Self-hosted fonts, under SIL Open Font License 1.1 (included alongside each font).

- [Inter variable font](https://github.com/google/fonts/tree/main/ofl/inter)
- [Noto Sans JP variable font](https://github.com/google/fonts/tree/main/ofl/notosansjp) (Japanese fallback)
- [Cormorant Garamond variable font](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond) (editorial brand and Latin headings)
- [Noto Serif JP variable font](https://github.com/google/fonts/tree/main/ofl/notoserifjp) (Japanese section headings)

Inter matches the font-family used by the [reference design](https://www.uistyleguide.com/style/3d-product-preview). Fonts are served locally without a runtime font CDN.
