# Color2GDS コンパイラ仕様

画像、最小線幅・間隔、GDSレイヤ、積層構造を入力に、GDSとその予測外観を生成します。画像の拡張子はjpeg/jpg/png/pbm/pgm/bmp。PNGの透明画素は配線なしとなり、予測表示ではモデル化した下地の反射色になります。黒色を透明の代用として扱いません。

## 起動と基本操作

依存関係は[uv](https://docs.astral.sh/uv/)で管理しており、Python 3.10で確認しています。初回は`uv sync`を実行してください。材料データは`data/`に同梱しています。

以前のスクリプトと同様の3つの位置引数に、積層構造を追加した形式です。

```bash
uv run python -m scripts.compile_image samples/zundamon.png 0.14 68 \
  --stack presets/sky130.yaml --out runs/my_sky130
```

幅と間隔を別々に指定する完全なCLIです。

```bash
uv run python -m color2gds compile samples/zundamon.png \
  --stack presets/soi_al.yaml \
  --min-width-um 0.14 --min-space-um 0.14 --gds-layer 1 \
  --pixel-size-um 7.815 --columns 128 --out runs/my_soi
```

初期値は128列、正方形画素7.815 µm。同梱のずんだもん画像は128×262画素、設計キャンバス1000.32×2047.53 µmです。透明な余白も含む寸法であり、金属の外接矩形の大きさとは異なります。`minimum_size_um`は光学画素のサイズではなく、線幅と間隔の下限です。

既存の出力フォルダへの上書きは拒否します。別名を指定してください。計算済みスペクトルは`.cache/color2gds/`に再利用可能な形で保存します。

## 出力

| ファイル | 内容 |
|---|---|
| `image.gds` | 階層GDSII、長さ単位1 µm、DBU 1 nm |
| `image.bmp` | 画素単位の配線あり／なしの二値画像。微細線そのもののマスク画像ではない |
| `appearance.png` | GDS読み戻し後に計算した画素平均の予測sRGB画像 |
| `appearance_large.png` | 同画像の最近傍拡大。色のコントラスト強調なし |
| `appearance.npz` | 波長、セル別反射率、セル別sRGB/Lab、画素→セルインデックス |
| `manifest.json` | 展開済み積層、GDS対応、入力ハッシュ、計算条件、画素配置規約 |
| `readback.json` | GDSハッシュ、GDSから抽出した形状、幾何検証結果 |
| `summary.json` | 色差、探索履歴、モデルと読み戻し後の一致、限界 |
| `palette.npz` | 最終候補ライブラリのスペクトルと色 |
| `calibration_*.gds` | 各探索段階の光学キャラクタライズ用セル |
| `layout_detail.png` | 実際のGDSポリゴンから描いた拡大図 |
| `report.html` | オフラインで開ける単体レポート |

NPZの読み込み例です。

```python
import numpy as np
a = np.load('runs/my_soi/appearance.npz')
# wavelength-dependent reflectance of pixel (row, column)
R = a['cell_reflectance'][a['pixel_cell_indices'][row, column]]
```

## 閉ループ処理

1. 最小幅・間隔とグリッドに従って矩形線格子をGDS化。
2. キャリブレーションGDSを読み戻し、実際の線幅・周期・本数・長さからRCWAを計算。
3. 画像をこのパレットへ割り当て、よく使われるセルの線幅を±1グリッド追加探索。
4. 追加前後の平均ΔE76を比較。候補追加による最適化の目的関数は固定。
5. 画像GDSを出力した後、形状と配置を再び読み戻す。
6. 復元形状から予測外観・スペクトルを生成し、最適化時の予測と一致することを検証。
7. 元画像に対するΔE00も別途評価。

`--refine-rounds 1`が初期値です。0なら候補追加なし、2以上なら追加探索を繰り返します。これは有限候補内の局所探索であり、全形状の大域的最適解を意味しません。前進モデルが同一なら最終読み戻し後の色差は数値誤差程度になりますが、実チップの測定との一致を意味しません。

`--mapping color`が初期値で、元のRGB色を目標にします。`--mapping contrast`は入力の明度・彩度を初期パレット内へ圧縮してから最適化します。後者は元の色を意図的に変えるため、目的関数に対する誤差と元画像に対する誤差を区別します。現行版は画素ごとの最近傍Lab割り当てであり、ディザリングは行いません。

## 生成・編集したGDSの再計算

```bash
uv run python -m color2gds simulate runs/my_soi/image.gds \
  --manifest runs/my_soi/manifest.json --out runs/my_soi_resim
```

この経路は元画像や最適化時のセルIDを使いません。GDSの矩形と参照配置を実際に読みます。対応外のポリゴン、配置、レイヤ、線幅違反などは停止します。積層に対する勝手なレイヤ置換で光学位置を変えることはできません。

## 対応する積層構造

対応範囲は上から下への等方的な平面積層と、**全パターン層が同じ1D矩形線格子を共有する単一マスク**です。任意の膜数・膜厚・材料の並びをYAMLで変更できます。入射媒質は空気、上下の端は半無限媒質で厚さ0、内部の膜厚は正の有限値が必要です。独立した複数マスク、穴・交差格子、2Dパターン、異方性、粗さ、非平面膜、自由形状GDSは未対応です。

既知の材料は `air`, `Al`, `Si`, `TiN`, `SiO2`, `Si3N4` です。Al/Si/TiNは保存済み文献n,k、SiO2/Si3N4は文献分散式。任意の固定n,k材料は`materials: {myfilm: {n: 1.7, k: 0.01}}`で追加できます。SKY130 PDKの静的誘電率を光学屈折率に換算してはいません。

### SKY130

`presets/sky130.yaml`はMet1、GDS 68/20、公開寸法を基にした探索モデルです。上層メタルがない領域を酸化膜とみなす平面化、PIのn=1.65/k=0などの仮定があります。**30 nm TiNキャップは未確定の仮定**です。公開図の30 nm寸法・NILD3_CというラベルからTiN材質を確定することはできません。今回の入力ファイルはその仮説を明示して引き継いでいます。TiN層を除去しAlを360 nmにするモデル等との比較が必要です。

固定レイヤ設定のため、`--gds-layer 69`を同じMet1積層に指定するとエラーになります。Met2を使う場合は対応する高さ・酸化膜・GDS番号を持つ別の積層定義を作成してください。

### SOI＋Al

`presets/soi_al.yaml` は空気／Al格子100 nm／Siデバイス層220 nm／BOX酸化膜2 µm／半無限Si基板の構成です。膜厚はケーススタディの仮定値です。付着層・自然酸化膜は初期モデルでは省略。GDS番号は任意のマスク番号に変更でき、物理的なAlの位置はYAMLで決まります。この寸法ルールはSKY130相当の比較条件であり、SOI製造プロセスのDRC認証ではありません。

## 検証と物理モデルの制約

初期設定は31保持フーリエモード、380–780 nmを1 nm刻み、垂直入射・非偏光、D65／CIE 1931 2°、0次正反射です。`--modes 51`, `--step-nm 0.5`で収束を調べられます。`--angle-deg`は正反射方向に観測を追従する条件で、顕微鏡NA積分ではありません。

全候補のRCWAで受動性とR+Tをチェックします。独立した平坦膜Fresnel解との比較、GDSの改ざん・レイヤ不一致検出をpytestで検証します。各画素は8周期以上とし、周辺の空白領域を非干渉の面積平均で含めます。有限画素の端部や隣接画素との電磁結合は計算していません。

GDSのグリッド・線幅・間隔・最小面積・画素境界間隔は検証します。これは全チップの密度・ダミーフィル・アンテナ・製造フロー適合性の保証ではありません。特に光学領域の上にダミー金属を加えると予測モデルが変わります。Magic検証結果があっても、製造可否と光学モデルの確定は別途必要です。

```bash
OPENBLAS_NUM_THREADS=1 uv run pytest -q
```

光学・PDKの出典は各YAMLと`data/*.yml`を参照してください。
## 同梱サンプルでの検証結果

同梱の2画像（ずんだもん・四国めたん）を幅1000.32 µm、横128画素で、SKY130とSOI＋Alの両積層について実行しました。元画像との平均ΔE00は、ずんだもんがSKY130で17.72、SOI＋Alで16.26、四国めたんがSKY130で17.57、SOI＋Alで14.40です。最終GDS読み戻しによる予測の差は全ケースで0でした。

各ケースの使用頻度上位2セルずつを次数51および波長刻み0.5 nmで再計算したとき、基準計算からの変動は最大ΔE00 0.311でした。SKY130の2ケースはMagic 8.3.678のdrc(full)でエラーカテゴリ0件でした（密度・アンテナ・製造サインオフを含みません）。検証記録は各ケースのnumerical_checks.jsonとmagic_drc.txtにあります。

```bash
uv run python -m scripts.check_compiler_drc runs/sky130_zundamon --magic "$(command -v magic)" --pdk-root "$HOME/.volare"
```
